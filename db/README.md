# Міграції

Виконуються вручну: **Supabase → SQL Editor**, проєкт `marinek-store`
(ref `cdkexaplxybsldondifk`, організація Марини). MCP-підключення цю
організацію не бачить, тому автоматом їх не накотити.

| Файл | Що робить | Стан |
| --- | --- | --- |
| `001_orders.sql` | Таблиця `orders` — замовлення, статуси, інвайти | Накочена 25.07.2026, до появи цієї папки. SQL зберігся лише в історії чату, у репозиторії його немає — актуальну схему дивитись у [netlify/lib/db.ts](../netlify/lib/db.ts). |
| `002_content.sql` | `site_content`, `results`, приватний bucket `results`, RLS під `authenticated` | |

Кожен файл написаний так, щоб його можна було виконати повторно
(`if not exists`, `on conflict`, `drop policy if exists`) — на випадок,
коли незрозуміло, накотили його вже чи ні.
